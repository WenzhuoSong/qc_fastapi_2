# Scout v2 优化方案（2026-10-27 确认）

## 一、定位
**决策辅助型研究工具，不是量化系统。** Scout 用业内认可的分析框架，把每个视角的结论、证据和"这个视角过去有多可靠"交给用户；买卖由用户决定。

不变的原则：数字只来自 Python；AI 只写解读并经过程序校验；外部信息标明来源；系统不下单；不按回放结果调参。

## 二、已确认的决定
| 事项 | 决定 |
|---|---|
| 存储 | **不为省成本牺牲表现**：所有时间点快照、分析结果、判断台账、文档全文和索引都完整保存，不做裁剪；磁盘不够由用户扩容（Railway 卷） |
| Massive Starter（$29/月） | **暂不订阅**。第 1 阶段完成、看过数据质量后再决定 |
| 期权资金流（Unusual Whales API，约 $150/月） | 等校准表证明期权视角有参考价值时再考虑 |
| 深度覆盖范围 | 研究池约 150 只：持仓 ∪ 活跃机会 ∪ 自选股 ∪ 成交额前 100（期权快照、文档阅读、研究备忘录只做这部分；全量约 900 只做轻量数据） |
| AI 预算 | 先按每月约 $30 规划，超出时优先保证持仓股 |
| 产品布局 | 功能完成后再统一整理 |

## 三、数据层（几乎全部免费）
| 类别 | 内容 | 来源 | 频率 |
|---|---|---|---|
| 行情 | 日线、盘中报价 | yfinance（Massive 暂不订阅） | 收盘后 / 盘中 15 分钟 |
| 财务 | 完整季度 / 年度报表历史 | SEC EDGAR companyfacts（官方） | 每天检查新文件 |
| 文件 | 8-K（财报新闻稿、指引）、10-K/10-Q、Form 4、13F | SEC EDGAR submissions | 每天 |
| 预期 | EPS / 营收预期、预期修正、目标价、评级变动 | yfinance | 每天快照 |
| 持仓与做空 | 机构持仓、做空比例、回补天数 | yfinance（源自 13F、FINRA） | 每天快照（源数据按季 / 两周更新） |
| 期权 | 期权链汇总：平值隐含波动、期限结构、偏斜、预期波动幅度、看跌看涨比、异常成交 | yfinance | 每天收盘后快照 |
| 宏观 | 利率、美元、油价、VIX、通胀 | FRED（免 key 的 CSV 下载） | 每天 |
| 新闻 | 个股 / 宏观新闻、RSS、按需网络检索 | Finnhub + RSS + OpenAI web search | 30 分钟 / 按需 |

设计要点：
1. **统一接口、可替换**：每类数据一个模块，付费源以后作为适配器接入，上层代码不变。
2. **时间点存储**：每份快照带获取日期，追加保存、不覆盖，保证日后评估时能还原"当时看到了什么"，不混进事后信息。
3. **质量控制**：价格交叉校验（yfinance 对照 Finnhub）、每条数据带来源和获取时间、过期标记、数据源失效时降级显示。
4. **请求节流**：EDGAR ≤ 10 次/秒且带联系邮箱，Finnhub 60 次/分钟，yfinance 控制并发。

## 四、分析层：从 8 个视角扩展到约 15 个
已有：道氏趋势、支撑阻力、动量与相对强度、均值回归与波动、大盘与板块、催化与事件、异常事件、基本面与预期（快照）。

新增：
1. **基本面趋势**：8–12 个季度的营收增速、毛利率 / 营业利润率、现金流方向（EDGAR）。
2. **估值位置**：市盈率、市销率、EV/EBITDA 相对自身历史和同行的分位。
3. **预期与修正**：30/60/90 天预期变化、上调 / 下调次数、目标价空间。
4. **财报事件**：业绩对比预期、指引变化（AI 读 8-K 新闻稿原文）。
5. **持仓与资金**：内部人集中买入、机构持仓变化、做空比例和轧空风险。
6. **期权市场的预期**：隐含波动位置、偏斜、财报前预期幅度、异常成交。
7. **竞争与产业链**：从 10-K 抽取竞争对手 / 供应商 / 客户，自动关联同业传导。
8. **宏观敏感度**：对利率、美元、油价的敏感程度。
9. **情景分析**：乐观 / 基准 / 悲观情景、触发条件、催化剂日历。

综合判断：视角之间的矛盾必须明确写出；各视角权重来自校准表，而不是人为设定。

## 五、AI 层：从被动回答到持续研究
1. **公司档案**：每家公司的结构化时间点数据。
2. **文档阅读员**：10-K/10-Q/8-K/重要新闻 → 带原文引用的结构化要点；每份文件读一次并缓存；程序校验引用确实存在于原文。小模型抽取。
3. **研究备忘录**：每只股票一份（投资逻辑、驱动因素、风险、催化剂日历、失效条件），有新信息时增量修改并写明"变了什么、为什么"。
4. **主动触发**：备忘录里可由程序检查的条件交给程序盯，满足即推送。
5. **带出处的检索**：文件全文和新闻按段落建索引（Postgres + pgvector），回答必须带出处。
6. **两步式解读**：各视角分别判断（可并行、可缓存），再做一次综合，避免证据包过大导致慢、贵、漏视角。

## 六、记忆与追踪
1. **判断台账**：记录所有判断（规则机会卡、AI 解读各视角、异动归因、备忘录逻辑和失效条件），以及当时的价格和数据快照。
2. **自动打分**：5 / 20 / 60 个交易日后相对 SPY 和板块的表现、失效条件是否触发、归因是否被证实。
3. **校准表**：各视角历史可靠度，显示在页面，交给 AI 作权重参考，写进周报。
4. **个股记忆**：再分析时 AI 看到"上次判断了什么、后来怎样"，必须回应。
5. **防止自欺**：样本不足只显示不调整；调整需要后一段时间样本也成立；每月抽检 10 条由用户人工打分。

## 七、影响与应对
| 方面 | 影响 | 应对 |
|---|---|---|
| 月成本 | 数据 $0；AI 约增加 $10–30 | 研究池 150 只；按日期缓存；小模型做抽取 |
| 速度 | AI 解读可能变慢 | 两步式 + 并行；数据在后台预抓 |
| 可靠性 | yfinance 非官方 | 统一接口、交叉校验、过期标记、降级显示 |
| 质量 | 证据越多越容易错引、漏视角 | 分批生成、分视角校验、评估集加入已知原因的历史事件 |
| 存储 | 快照、文档全文、向量索引持续增长 | 完整保存；用量接近上限时提醒用户扩容 |
| 现有功能 | 盘前简报、收盘卡片、盘中提醒都可接入新数据 | 新功能完成后逐个接入 |

## 九、第 1 阶段实施记录（2026-10-27）
- **研究池**：113 只（持仓 ∪ 活跃机会 ∪ 自选 ∪ 成交额前 100，只含个股）；期权快照另加 SPY、QQQ、IWM。
- **SEC EDGAR**（`scout/data/sec.py`）：代码 → CIK、文件索引（8-K 含 item，2.02 = 财报）、XBRL 季度财务 20 个指标、约 20 年历史。
  现金流只有年初至今累计值，单季由相邻累计值相减；Q4 = 全年 − 前三季。校验：Apple FY2025 四个季度合计与 10-K 一致（营收 4161.61 亿、经营现金流 1114.82 亿美元）。
  每次申报保存一行，重述会新增一行，查询时按"当时已申报"取值；只有出现新的 10-Q/10-K 才重新拉取财务数据。
- **Yahoo**（`scout/data/yahoo_research.py`）：预期、预期趋势（7/30/60/90 天）、修正次数、目标价分布、评级变动明细、持仓与做空、估值倍数，每日快照。
- **期权**（`scout/data/options.py`）：Yahoo 在非交易时段的报价和持仓量都是 0、隐含波动不可用，所以只在 15:30–16:00 美东取一次，
  用买卖中间价按 Black-Scholes 自行计算隐含波动；输出平值隐含波动、跨式隐含涨跌幅、10% 虚值偏斜、看跌看涨比、异常成交（成交 ≥ 500 且 ≥ 2 倍持仓量）。
  持仓量缺失时不做异常判断。
- **FRED**（`scout/data/fred.py`）：11 个序列（3 个月 / 2 年 / 10 年美债、期限利差、联邦基金利率、美元、原油、VIX、高收益利差、CPI、失业率）。
- **质量与存储**：每天用 Finnhub 报价交叉校验收盘价（偏差 > 0.5% 记录）；数据源失败写入 `scout.data_quality`；数据库超过卷的 80% 推送扩容提醒；
  页面 `/data` 显示覆盖、新鲜度、质量问题、任务和存储。
- **定时任务**：`scout-research`（每个交易日 23:30 UTC，收盘扫描之后）、`scout-options`（15:30–16:00 美东之间执行一次）。

## 十、第 2 阶段实施记录（2026-10-27）
- **记录什么**（`scout/ledger.py`，表 `scout.judgments`）：每次 AI 解读的综合倾向（各视角偏多/偏空的净方向）和每个视角的判断、每张规则机会卡、
  每天 11 个板块的热度（热 = 偏多、冷 = 偏空），连同数据日期、当时价格、所属板块 ETF。同一数据日期重复生成会覆盖，不重复计数。
- **怎么打分**（表 `scout.judgment_outcomes`）：每天收盘扫描时，对到期的判断计算 5 / 20 / 60 个交易日后相对 SPY 和相对板块的超额。
  偏多 = 跑赢 SPY 为命中；偏空 = 跑输为命中；中性 = 超额在 ±1.5% / ±3% / ±6% 以内为命中。
- **校准表**：按类别 × 视角 × 判断方向统计命中率和超额中位数；少于 30 个样本只显示、不使用。显示在 `/ledger`、周报，并以
  `lens_reliability` 交给 AI，要求降低不可靠视角的权重。
- **个股记忆**：再次解读同一只股票时，AI 看到之前 3 次的结论和后来的走势，必须在置信度说明里回应，判断错了要承认。
- **人工抽检**：`/ledger` 每条判断可以打 👍👎（写得是否合理，与结果无关），周报提示本月抽检数（目标 10 条）。

## 十一、第 3 阶段实施记录（2026-10-27）
- **14 个视角**（`scout/knowledge/lenses/01–14_*.md`）：原有 7 个（道氏趋势、支撑阻力、动量与相对强度、均值回归与波动、大盘与板块、
  催化与事件、异常事件），新增 7 个：基本面趋势、估值位置、预期与修正、财报事件、持仓与资金、期权市场的预期、宏观敏感度。
  原"基本面与预期"快照视角拆入新视角。
- **计算**（`scout/research.py`，纯函数 + 时间点加载）：
  - 基本面趋势：营收同比与增速变化、毛利率 / 营业利润率及其同比变化、近 4 季自由现金流与自由现金流率、净现金、稀释股本一年变化；
    外国公司（IFRS、年度申报、非美元）按年度计算，不做跨币种的绝对金额。
  - 估值位置：市盈率（近 4 季 EPS）、预期市盈率、市销率、市值 / 自由现金流、EV/EBITDA、EV/营收；市销率在约 3 年季末历史中的分位；
    EV/营收、预期市盈率相对研究池同行业中位数。
  - 预期与修正：本财年 EPS 预期 30 / 90 日修正、上调 / 下调人数、下一财年预期增长、目标价空间与分歧度、30 日评级和目标价变动次数。
  - 财报事件：上次 EPS / 营收超预期、按 SEC 8-K 2.02 发布日计算的历次财报股价反应（最多 8 次）、平均财报波动、期权隐含的财报波动 / 历史。
  - 持仓与资金：机构 / 内部人持股、做空比例、回补天数、空头变化、前十大机构增减持、内部人 90 日净买卖。
  - 期权：近月 / 30 天平值隐含波动、隐含 / 实际波动、期限结构斜率、跨式隐含涨跌幅、看跌偏斜、看跌看涨比、异常成交数、隐含波动历史分位（满 60 天后）。
  - 宏观敏感度：近 252 个交易日回归（个股 ~ SPY + 10 年期收益率变化 + 美元 + 原油），给出每 +10bp / +1% / +10% 的影响和 t 值，只解读 |t| ≥ 2。
- **信息截止日**：实时解读使用截至今天已知的数据；回放时传入历史日期，财报只取当时已申报的版本、快照只取当日及之前的。
- **研究池以外的股票**：生成 AI 解读时按需抓取 SEC 和 Yahoo 数据（约 10–20 秒），快照照常保存。
- **AI 两步式**（`scout/insight.py`）：第一步 4 组并行（技术与市场 5 个视角、事件与财报 3 个、基本面与预期 4 个、期权与宏观 2 个），
  每组只看自己的证据、方法和相关背景，分别校验和重试，失败只回退这一组；没有任何数据的组不调用 AI。第二步综合：结论、近期异动、
  驱动力、视角矛盾、关注 / 失效条件、主要风险、置信度（回应历史判断、参考各视角可靠度）。
- **页面**：个股页新增「研究数据」卡（7 个视角的数据、读数、季度财务表、评级变动、快照日期），替代原基本面卡；AI 解读卡显示"视角矛盾"。
