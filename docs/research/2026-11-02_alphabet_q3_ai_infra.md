# Alphabet 2026 Q3 与 AI 基础设施产业周期

## 核对说明

- ✓ 表示与 Scout 数据一致：Alphabet 2026-10-29 提交的 10-Q（Scout 的 SEC 财务数据）和 Scout 的日线行情。
- "外部报道（未经核实）"：来自检索，Scout 没有对应数据。
- "Scout 暂时无法核对"：10-Q 里有，但 Scout 目前没有提取（分部数据、RPO、承诺事项）。

## 一、结论

Google 的经营业绩仍然强劲，但资本投入的增长快于现金创造。市场担心的不是 AI 没有需求，而是巨额投资能否带来足够的回报。

- **公司经营：强。**营业利润同比 +30%，Google Cloud 收入翻倍、利润率提高。
- **股价：转向谨慎。**财报后单日 −12.6%，反映了 EPS 低于预期、搜索变现的担忧，以及市场重新评估资本开支。
- **行业周期：短期供给紧，长期回报不确定。**HBM、电力和高端算力仍有瓶颈；2027–2028 年大量新产能上线后，价格和利用率可能变化。

## 二、财报（2026 Q3，10-28 公布）

| 指标 | 数值 | 核对 |
|---|---|---|
| 营收 | $127.6B，同比 +25% | ✓ $127.58B |
| 营业利润 | $40.6B，同比 +30% | ✓ $40.58B |
| 净利润 | 约 $26.5B | ✓ $26.47B |
| 稀释 EPS | $2.12，同比 −26% | 未单独核对 |

**EPS 为什么下降：**营业利润在增长，EPS 却下降，原因在非经营性的投资损益。笔记原稿说，2025 Q3 的股权投资收益约 +$10.7B，2026 Q3 约 −$8.7B（未单独核对）。

**核对时补充的一点：**Google 2026 年前两个季度的净利润是 $62.6B 和 $112.2B，远高于约 $40B 的营业利润，说明投资收益的波动很大。**看 Google 应该看营业利润和自由现金流，EPS 的同比变化没有太大意义。**

**Cloud 的增长要分开看：**103% 里有一部分来自 TPU 系统销售，不全是持续性的云服务消费（据笔记原稿）。

## 三、股价为什么暴跌

- 10-29 单日 −12.6%（✓ 324.89 → 283.82），10-30 收盘 $279.84（✓）。外部报道称这是二十多年来最大的单日跌幅、蒸发约 5,000 亿美元市值（未经核实）。
- 四个原因：
  1. EPS 低于预期；
  2. 搜索收入增速从约 17% 放缓到 12%，AI 搜索的变现还不成熟；
  3. 当季资本开支 $51.4B，自由现金流转负；
  4. 暂停回购，增加股票和债务融资（据笔记原稿，未经核实）。
- **学到的一点：**经营好不等于股价涨。股价反映的是实际结果和此前预期之间的差距，以及市场对未来现金流的重新估值。

## 四、利润和现金流开始背离（核心）

| 单位：十亿美元 | Q1 | Q2 | Q3 | 核对 |
|---|---|---|---|---|
| 经营现金流 | 45.79 | 39.07 | 42.29 | ✓ |
| 资本开支 | 35.67 | 44.92 | 51.36 | ✓（Q3 为 51.35） |
| 自由现金流 | +10.12 | −5.86 | −9.07 | ✓（两项相减） |
| 资本开支 / 经营现金流 | 78% | 115% | 121% | ✓ |

- 自由现金流为负，不等于缺钱：现金加有价证券约 $265.1B（✓ 现金 $56.33B + 短期投资 $208.76B）。但这说明公司进入了一个新的资本投入阶段。
- 需求承诺和建设中的产能（Scout 暂时无法核对）：
  - Google Cloud RPO $560.8B，约 55% 预计在 24 个月内确认；
  - 尚未投入使用的资产 $145.3B；
  - 未来采购承诺约 $924.4B，尚未开始的租赁付款承诺 $130.5B。
- **注意：**RPO 不等于已经收款，更不保证利润；也不能把 RPO 和各项承诺直接相减来估算利润。

## 五、产业链：不只是 GPU

最终付费需求（AI 应用、企业 API、智能体）→ 云平台（Google Cloud、AWS、Azure、CoreWeave）→ 算力硬件（GPU / TPU、HBM、DRAM、SSD、网络）→ 物理基础设施（数据中心、电网、电力、冷却）

1. **内存是瓶颈**（外部报道，未经核实）：
   - TrendForce 预计 Q4 常规 DRAM 合约价环比上涨 10–15%，NAND 上涨 15–20%；
   - SK hynix 称长期供应协议已覆盖其 2027–2028 年规划产能的 50% 以上。
2. **算力价格不是单向变化**（外部报道，未经核实）：
   - 旧一代 GPU 的租赁价格在下降，同等任务的成本也在快速下降；
   - 但 CoreWeave 披露，部分新签短期合同提价了。
   - 要区分三件事：硬件售价、算力租赁价格、完成同样任务的实际成本。
3. **电力和数据中心交付可能比芯片更难解决**：IEA 估计约 20% 的规划项目可能因电网接入而延误（外部报道，未经核实）。
4. **中间环节的需求不等于最终需求**：AI 创业公司先签下巨额算力合同，再去卖产品。云厂商的合同储备不能直接当成最终用户的消费。

## 六、Google 和 CoreWeave 要分开看

| 维度 | Google | CoreWeave |
|---|---|---|
| 资金来源 | 成熟业务的现金流，加融资 | 资本市场融资、以合同为支撑的融资 |
| 核心风险 | 资本回报、搜索的 AI 变现、投资效率 | 利息成本、利用率、债务、合同交付 |
| 最该看什么 | Cloud 利润和集团自由现金流 | EBITDA 能否转化为净利润和自由现金流 |

据外部报道（未经核实）：CoreWeave 2026 Q2 营收约 $2.58B，净利息费用约 $640M，净亏损约 $626M。**需求强、营收快速增长、EBITDA 很高，都不保证股东最终赚到钱。**

## 七、以后固定看的几组关系

| 关系 | 回答的问题 |
|---|---|
| Cloud 收入增长 vs 资本开支增长 | 新增投入有没有带来相应的营收规模？ |
| Cloud 营业利润 vs 折旧和运营成本 | 收入增长能否覆盖不断上升的成本？ |
| RPO 增长 vs 实际确认的收入 | 客户的承诺有没有兑现？ |
| 有效算力供给 vs 最终付费需求 | 行业是在持续短缺，还是开始过剩？ |
| AI 服务单价 vs 单位计算成本 | 技术进步带来的成本下降，能否超过降价？ |
| 自由现金流、ROIC vs 资本成本 | 投资最终有没有增加股东价值？ |

**三种情景**（研究假设，不是概率）：
- **乐观**：需求持续超过有效供给，Cloud 利润率维持，资本开支增速放缓后自由现金流恢复。
- **中性**：规模继续增长，但降价抵消了部分增长，利润率承压，自由现金流恢复得慢。
- **悲观**：新增供给超过真实需求，算力价格下跌，折旧和融资负担加重，利用率下降。

## 八、和持仓的关系（核对时补充）

- **MU** 是这条产业链上的存储器供应商：云厂商的资本开支就是它的需求来源（Scout 的公司画像显示，NVDA 年报写明向 Micron 采购存储器）。
- "内存供给紧张"是 MU 现在利润高的原因；"2027–2028 年产能过剩"的悲观情景则是它最大的风险。见上方论点 `memory_tight_2027` 和 `capacity_glut_risk`。

## 九、结论

> Alphabet 2026 Q3 证明核心业务仍有较强的增长能力，Google Cloud 的收入和营业利润都在高速增长。但资本开支快速上升，自由现金流连续两个季度为负，加上搜索增速放缓、AI 搜索变现仍不确定，市场重新评估了它未来的资本回报，股价因此大跌。
>
> 从行业看，2026 年高端算力、HBM、服务器内存和电力仍然供给紧张，但大量产能正在建设。2027–2028 年新产能释放后，决定产业盈利能力的不只是 AI 用量的增长，还有单位算力价格、硬件成本、利用率、折旧，以及终端客户能否持续付费。
>
> 现在能确认的是 AI 需求和商业化在增长；还不能确认的是，如此大规模的投入最终能否给股东带来足够的回报。
