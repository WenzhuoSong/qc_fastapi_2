# Scout v3 方案：AI 研究台与可验证的知识库（2026-10-28 确认，按阶段开发）

## 一、目标

Scout 从"规则找机会"转为**会学习的研究台**：

1. **专业分析**：AI 用完整的分析框架给出结论，并写明依据和失效条件。
2. **发现规律**：AI 从经济机制出发提出假设，用 Python 检验。
3. **行业前景**：AI 从新闻、财报、产业链等客观信息判断行业和主题的前景，提前布局。
4. **增量学习**：新的技术、策略和知识只有在对应的情境下被确认有效后，才写进知识库。

不变的原则：
- 数字只来自 Python；
- AI 写的内容要经过程序校验；
- 外部信息标明来源；
- 不按回放结果调参；
- 历史数据不裁剪；
- **Scout 不向 QuantConnect 或券商发送任何订单或指令**。

## 二、出发点：已有证据

| 结论 | 证据 |
|---|---|
| 原来的"相对持有"基准偏高（用了整段历史的平均涨幅，叠加当前成分股的偏差） | `eval_rules`，2026-10-28 |
| 7 条规则里，只有"突破回踩"（候选）在前后两半都胜过同日随机选股（t 3.8 / 3.3），但相对 SPY 只有 +0.2–0.3%：交易方式吃掉了大部分选股信息 | 同上 |
| 强势回调只在前半段有效；放量跳空、放量异动没有显著结果；趋势突破、板块轮动龙头、z 分数超跌没有优势 | 同上 |
| 价位图的回调买点前后两半都不如直接买入；突破买点必须放量收盘确认；盘中触及就买最差 | `eval_levels`，2026-10-27 |
| 出场：不分批 > 目标 1 卖 1/3 + 吊灯止损 > 目标 1、2 各卖 1/3 | `eval_exits`，2026-10-27 |
| B0：出场、择时、支撑阻力叠加 9 轮失败；B0 80% + GLD 20% 通过；TSMOM 第二引擎通过验收标准 A 和 B | B0 Optimization 会话 |

这些结论说明两件事：**假设的质量比检验的数量重要；检验必须公平而且严格**。这两点是下面设计的核心。

## 三、总体结构

```
 假设来源                     检验关                          知识库                 使用
 ───────                     ──────                          ──────                 ────
 文献 / 机制推理   ──┐
 新闻·财报·产业链 ──┼─→ 预登记 → 回测 → 批判 → 前向 → 确认 ─→ 已确认知识 ──→ AI 解读与周报（按情境调用）
 B0 的研究结果    ──┤        （不通过的写成"否定知识"）        否定知识   ──→ 提假设前先查，避免重复
 你的想法         ──┘                                         待验证     ──→ 页面标"未验证"
                                                                          ──→ 给 B0 的特征和策略规格（离线）
```

分工：AI 负责提假设、实现、检验、批判和解释；Python 负责所有数字；你批准每一次转为已确认。

## 四、知识库

### 4.1 每条知识的字段（新表 `scout.knowledge`，历史版本全部保留）

| 字段 | 含义 | 例子 |
|---|---|---|
| `kind` | 类型：`rule` 交易规则 / `feature` 特征 / `regularity` 市场规律 / `method` 分析方法 / `judgment` AI 判断类 | `rule` |
| `claim` | 一句话结论 | 突破后回踩不破的股票，未来持有期跑赢同日随机股票 |
| `mechanism` | 为什么会成立、为什么还没被套利掉 | 突破后的回踩洗掉短线获利盘，供给减少 |
| `context` | 成立的条件（JSON）：市场状态、市值、行业、持有期、流动性 | `{"regime": "any", "horizon_days": 20, "universe": "S&P 1500"}` |
| `evidence` | 检验记录：brief id、样本区间、前后两半的结果、t 值、对照方式、成本 | `rule_benchmarks` 2026-10-28 |
| `status` | 状态，见下 | `forward` |
| `polarity` | `positive` 有效 / `negative` 无效 | `positive` |
| `invalidation` | 出现什么情况就要重新检验 | 滚动 24 个月相对选股对照 t < 0 |
| `recheck_on` | 下次复查日期 | 2027-04-28 |
| `supersedes` | 取代了哪条旧知识 | — |
| `approved_by` / `approved_at` | 谁、何时批准转为已确认 | 用户 |

**状态流转**（不可跳步）：

1. `hypothesis`：已提出、已预登记；
2. `backtested`：通过回测；
3. `forward`：前向模拟中；
4. `confirmed`：你批准后确认。

旁路：任何一步不通过都转为 `rejected`，作为否定知识保留；已确认的知识复查时失效，转为 `retired`。AI 判断类知识无法回测，从 `hypothesis` 直接进入 `forward`。

### 4.2 知识怎么用

- **AI 解读和周报**：按当前情境（市场状态、行业、持有期）取出匹配的 `confirmed` 知识，写进提示词的依据部分；生成的文字必须注明引用了哪一条。`forward` 状态的知识可以展示，但页面标"未验证"。
- **提假设之前**：先检索 `rejected` 和 `retired`。换个说法重复试同一个想法，要算进同一族检验，不能当作新假设。
- **页面 `/knowledge`**：列出每条知识的状态、证据、复查日期；否定知识同样展示。

### 4.3 首批写入（来自第二节）

- **正向，`backtested`**：
  - 突破回踩的选股信息；
  - 放量收盘确认的突破买点优于盘中触及；
  - 出场：不分批、到目标 1 后才启用吊灯止损最好；
- **否定**：
  - 等回调买点不如直接买入；
  - 强势回调在后半段失效；
  - 趋势突破、板块轮动龙头、z 分数超跌没有优势；
  - B0 的 9 轮叠加。

B0 的结论在你确认后再录入。

## 五、检验关

所有门槛**现在就定下来，之后不再根据结果调整**。

| 关 | 内容 | 通过标准 |
|---|---|---|
| G0 预登记 | 跑之前先写好规格：机制、数据、规则、对照、成功标准、预期在什么情况下失效。写入知识库，状态 `hypothesis`；跑过的每一个变体都算进同一族 | 规格完整；查过否定知识，没有重复 |
| G1 回测 | 沿用并推广 `eval_rules`：同期 SPY、等权股票池、时机对照、选股对照；扣成本；前后两半分开；按市场状态拆分；检查流动性和容量；检查和已有知识的重合度（信号重合、收益相关） | 主对照前后两半都为正；全样本 t ≥ 3（参考 Harvey、Liu、Zhu 2016 对多重检验的建议）；和已确认知识的收益相关 < 0.5，否则视为同一条 |
| G2 批判 | AI 按清单逐项检查：前视偏差、幸存者偏差、数据挖掘、拥挤、成本和滑点、是否只在单一时期成立；写出反方论证 | 每一项都有结论；有未解决的问题就退回 |
| G3 前向 | 从今天起按规则记录每个信号和对照，不改参数；AI 判断类知识走判断台账 | 至少 6 个月且至少 30 个样本；前向相对对照的超额 > 0，并且不显著低于回测（差值 t > −2） |
| G4 确认 | 你看过证据后批准 | 你的决定 |
| 复查 | 已确认知识每 6 个月复查一次；也可由失效条件触发 | 滚动 24 个月的超额 t < 0，转为 `retired` |

**说明**
- **为什么要前向**：AI 的训练数据包含过去十年发生的事，用历史回测 AI 的判断，结果是被污染的。判断类知识只认前向结果。规则类知识也要前向，用来防止回测本身过拟合。
- **为什么门槛是 t ≥ 3**：这次 56 个检验里，单凭运气就会出现 2–3 个 |t| > 2。

## 六、行业与主题前景判断

### 6.1 先描述"当前的主力"（Python 计算，不做预测）

- 每周把市场收益拆解到行业和风格（动量、规模、价值、低波动）上，看是谁在推动市场；同时统计资金在行业之间的轮动，以及市场宽度。
- 这部分是描述性的，不需要验证；它是 AI 判断前景时的事实依据。

### 6.2 AI 的前景判断：重点是扩散慢的信息

- **信息来源**：
  - 多家公司财报和电话会里同时出现的趋势（资本开支、订单、库存、定价）；
  - 产业链上下游的变化；
  - 监管和政策走向；
  - 宏观数据。
- **不追单条新闻**：价格对单条新闻的反应以分钟计，追不上。

**每条判断的记录**（判断台账新增类型 `sector_thesis`）：

| 字段 | 内容 |
|---|---|
| 对象 | 行业 ETF 或主题篮子（成分由 Python 按规则确定） |
| 方向与持有期 | 偏多 / 偏空，60 或 120 个交易日 |
| 机制 | 为什么、通过什么渠道影响盈利或估值 |
| 证据 | 引用的财报段落、数据、外部报道（标"据外部报道（未经核实）"） |
| 证伪条件 | 出现什么情况说明判断错了 |
| 复盘点 | 20 / 60 / 120 个交易日 |

**打分**：对照 SPY 和等权股票池，沿用台账的打分方式，持有期新增 120 个交易日。

**频率**：周报里每周最多 3 条新判断，避免量多质低。按这个频率，要一年左右才有 30 个以上样本可以评价校准。这个慢是绕不过去的；在那之前，所有判断都标"未验证"。

### 6.3 判断方法本身也进知识库

比如"多家公司同时上调资本开支 → 上游设备行业 120 天跑赢"。这是一条 `judgment` 类知识，按 G3 走前向检验。真正被积累和验证的，是方法，而不是某一次的结论。

## 七、从数据中发现规律

- **假设先于数据**：AI 从机制出发提出候选特征，Python 计算，按点位时间保存，加入 `features.yaml`，每个都要写明含义。
- **可以用机器学习**，但必须：
  - 做滚动前推的时间序列检验，训练集和检验集之间留出隔离期；
  - 用和 G1 相同的对照；
  - 模型输出当作一条 `feature` 类知识过关。
- **不允许无约束的大规模组合搜索**；每一族检验都在 G0 登记，有明确的规模上限。

## 八、和 B0 的接口（只有离线，不自动连接）

| Scout 提供 | 形式 | B0 怎么用 |
|---|---|---|
| 已确认的特征 | 点位时间的 CSV 数据集和计算说明 | 在 QC 里离线回测，看能否改进选股或排序 |
| 策略规格 | 知识库条目导出：机制、规则、对照、证据 | B0 会话独立实现、独立回测 |
| 行业 / 主题倾向 | 只用已确认的方法产生的判断，作为给你的建议 | 由你决定是否调整 B0 的股票池或配置 |

- B0 的研究结果，无论成功还是失败，都回写到 Scout 的知识库。
- 不做实时数据接入，不向 QC 发送任何内容。将来是否接入，是单独的决定。

## 十一、风险与限制

- **AI 过度自信**：靠证据字段、批判关和前向打分约束；不让 AI 自己批准任何知识。
- **反馈慢**：行业判断要一年左右才能评价。这是方法的代价，不是缺陷。
- **知识衰减**：公开的规律会被套利掉，所以设复查日期和失效条件。
- **成本**：P4 每周多几次 AI 调用，在每月约 $30 的预算内；不为省成本牺牲质量。
- **不做的事**：自动交易；按回放结果调参；不经过关就把 AI 的判断用于配置。

## 十四、P2 实施记录（2026-10-28）

门槛（用户 2026-10-28 确认，之后不再调整）：
- 回测：主对照前后两半都为正，全样本 t 不低于 3；
- 前向验证：至少 6 个月且至少 30 个样本；
- 复查：每 6 个月一次。

同一族检验次数多时，t 门槛按 Bonferroni 上调（只升不降，10 次以内仍是 3）。

- **G0 预登记**：
  - 规格文件放在 `scout/knowledge/specs/*.yaml`，跑过之后不再修改；改了想法就换一个 key，放进同一族；
  - 每次运行记入 `scout.gate_runs`（迁移 015），按族计数；
  - 一条知识登记过规格后，不能再登记新规格。
- **G1 回测**：`scout/gate.py`，`eval_rules` 也改用它。内容包括：
  - 四种对照；
  - 前后两半、各市场状态分开看；
  - 和其他规则比较信号重合度与月度收益相关度；
  - 每条规则用自己的随机数序列，增加或调整其他规则时，不会改变这条规则的对照结果。
- **G2 批判**：AI 按 7 项清单作答，数字要能在报告里找到。没有模型时不算通过。
  - 有两项（单一时期、重复）程序能直接核对。AI 判"不通过"而报告不支持时，要求它重写。
  - **只有回测失败才会被否定**；批判不通过只是退回，状态不变，问题写进记录。
- **命令**：`python -m scout.jobs.gate register <spec>` 和 `run <key>`；报告存为 brief `gate`；`/knowledge` 显示规格和最近一次检验结果。

**验收：突破回踩**（规格是看过 10-28 的结果后补登的，已在规格里注明）。
- **第 1 次运行（本族第 1 次）**：回测四项都通过，但 AI 批判有两处误判：
  - 单一时期：看错了对照那一列；
  - 重复：把和已否定的"趋势突破"重合当成了重复。

  当时的实现又让批判失败直接否定。这三个问题都已修正，否定已撤销（版本 4，理由写在记录里）。
- **第 2 次运行（本族第 2 次）：通过，状态为"回测通过（待前向验证）"**。
  - 相对选股对照：+0.74%（t 3.63）/ +0.92%（t 3.50），全样本 +0.83%（t 5.02）；

## 二十六、卖出方式 vs 一直持有（2026-10-28，预登记 `exit_vs_hold`，一次运行）

- **设计**：`scout/knowledge/exit_specs/exit_vs_hold.yaml`，提交于 2e850a6，在运行之前。
  - 2015-11 至 2026-07 共 135 批，每 20 个交易日全池次日开盘买入，共 102,941 笔；
  - 窗口 60 个交易日；提前卖出的钱按 3 个月美债计息；每笔扣 0.1%。
- **结果**（组合由 3 个交替的子组合构成）：

| 方案 | 年化 | 夏普 全部 / 前半 / 后半 | 最大回撤 | 最差 63 日 | 每笔均值 | 最差 5% 交易 | 提前卖出 | 平均持有 |
|---|---|---|---|---|---|---|---|---|
| 一直持有 | +17.4% | 0.81 / 0.978 / 0.633 | −39.7% | −37.2% | +3.95% | −31.1% | 0% | 60 天 |
| 现行持仓计划 | +7.4% | 0.87 / 1.28 / 0.48 | −6.1% | −4.1% | +1.63% | −10.3% | 95% | 19 天 |
| 计划 + 初始止损 ≥ 3 ATR | +8.9% | 0.89 / 1.32 / 0.52 | −8.6% | −6.5% | +1.93% | −14.7% | 92% | 25 天 |
| 10×ATR42（Wilcox） | +17.6% | 0.93 / 1.273 / 0.631 | −24.1% | −21.0% | +3.91% | −28.6% | 11% | 58 天 |
| 吊灯 3×ATR22（LeBeau） | +8.8% | 0.87 / 1.31 / 0.46 | −9.2% | −5.8% | +1.93% | −14.6% | 93% | 26 天 |
| 回落 20% | +15.1% | 0.86 / 1.18 / 0.57 | −22.8% | −20.1% | +3.38% | −23.5% | 19% | 55 天 |

- **判定**：没有方案满足事先定的三条，不推荐替换；知识库条目 `exit_vs_hold` 记为否定。
  - 五个方案都满足"回撤至少小 5 个百分点"和"最差 5% 交易亏得更少"；
  - 都没满足"前后两半的夏普都不低于持有"，后半段（2021-03 之后）全部落后。
- **Wilcox 方案差一点通过**：后半段夏普 0.631，持有是 0.633，只差 0.002。
  - 它的年化收益与持有相同，逐笔差 −0.04%，t −0.17；
  - 最大回撤从 −39.7% 降到 −24.1%，最差 63 日从 −37.2% 降到 −21.0%。
  - 按规则仍记为不满足。这个差距在噪声范围内，可以说它"风险调整后与持有持平、回撤明显更小"，但不能说"更好"。规则不因结果改动。
- **现行持仓计划的问题**：
  - 95% 的买入在 60 天内被止损或跟踪止损卖出，平均只持有 19 天，大部分时间拿着现金；
  - 回撤很小（−6%），但年化只有 7.4%，持有是 17.4%；每笔相对持有 −2.32%（t −3.91），前后两半都显著为负。
  - 加宽初始止损或改用 3 倍 ATR 的吊灯止损，作用都不大：3 倍 ATR 对 60 天的持有期仍然太紧。
- **与文献一致**：紧止损降低收益（Lo & Remorov 2017）；只有很宽的跟踪止损（Wilcox 10 倍 ATR、20% 回落）在保住大部分收益的同时降低尾部风险。
- **知识库**：`exit_scale_out_costs`（"不分批、到目标 1 后才用吊灯止损最好"）是在规则信号上、对比有偏的持有基准得出的，只在几种止损方式之间比较有效；相对一直持有，这套方式明显落后。

## 二十七、卖出后换仓，配合大盘与行业过滤（2026-10-29，预登记 `exit_redeploy`，一次运行）

- **设计**：`scout/knowledge/exit_specs/exit_redeploy.yaml`，提交于 ea3f2d5，在运行之前。
  - 买入与 `exit_vs_hold` 相同：135 批，102,941 笔；
  - 3 种卖出 × 2 种换入（股票池等权 / 资产增长最慢选股）× 3 种过滤（不过滤 / Faber 大盘 / 大盘 + 行业），共 18 个方案；另有 2 个基准；
  - 大盘过滤在 17% 的批次处于避险。
- **判定**：没有方案满足事先定的四条，不推荐替换；知识库 `exit_redeploy` 记为否定。
- **主要数字**（年化 / 夏普 全部、前半、后半 / 最大回撤 / 最差 5% 交易）：

| 方案 | 年化 | 夏普 | 最大回撤 | 最差 5% |
|---|---|---|---|---|
| 一直持有 | +17.4% | 0.806 / 0.978 / 0.633 | −39.7% | −31.1% |
| 一直持有 + 大盘过滤 | +13.1% | 0.760 / 0.924 / 0.605 | −31.1% | −29.5% |
| 现行计划，钱闲置（`exit_vs_hold`） | +7.4% | 0.87 / 1.28 / 0.48 | −6.1% | −10.3% |
| 现行计划 · 换入股票池 | +16.7% | 0.773 / 0.941 / 0.603 | −39.6% | −19.1% |
| **现行计划 · 换入资产增长选股** | **+19.0%** | **0.838 / 1.028 / 0.649** | −39.8% | −19.8% |
| 现行计划 · 换入股票池 · 大盘过滤 | +10.8% | 0.727 / 1.073 / 0.414 | −17.4% | −14.5% |
| 10×ATR42 · 换入股票池 · 大盘过滤 | +13.4% | 0.858 / 1.171 / 0.587 | −19.4% | −26.8% |
| 回落 20% · 换入股票池 · 大盘过滤 | +12.1% | 0.790 / 1.105 / 0.499 | −17.9% | −23.7% |

- **结论 1：止损的代价主要是资金闲置。**
  - 现行计划卖出后马上换入股票池，年化从 7.4% 回到 16.7%，每笔只比持有少 0.18%（换仓成本量级）；
  - 最差 5% 的交易从 −31% 降到 −19%：止损对单笔风险的保护几乎不花钱。
- **结论 2：单笔止损降不了组合回撤。**
  - 换回市场后，组合最大回撤仍是约 −40%，因为大跌时整个市场一起跌；
  - 只有大盘过滤能把组合回撤降到 −17% 至 −20%。
- **结论 3：这段样本里，大盘过滤的代价很高。**
  - 年化少 4 至 6 个百分点，后半段夏普都低于持有（2018 年底、2020 年 3 月、2022 年等多次在低位避险、错过反弹）；
  - 一直持有 + 大盘过滤，夏普 0.760 也低于持有的 0.806。
- **结论 4：行业过滤没有增益。**与只用大盘过滤几乎相同，或更差，和板块轮动被否定一致。
- **唯一在收益和夏普上两半都好于持有的方案**：现行计划 · 换入资产增长选股，年化 +19.0%，每笔 +0.57% / +0.33%（t 1.44 / 1.20）。
  - 它因为最大回撤没有减小（−39.8%）而不满足条件；
  - 它的超额来自资产增长选股本身，那条策略还在前向验证中，且受幸存者偏差影响最大。
- **用户的取舍**（不是检验结论）：
  - 想要单笔风险小、收益与持有接近：止损 + 立即换仓；
  - 想要组合回撤小：大盘过滤，代价是这段牛市里每年少 4 个百分点以上。

  - 资产增长 · 10×ATR42 · 上限 252 满足事先定的全部条件，知识库 `hold_cap` 记为回测通过；是否改持仓计划由用户确认。
  - 其他组合都不满足，包括所有现行计划的组合和全部突破回踩组合。
- **为什么现行计划的上限无关紧要**：它的止损太紧，绝大多数仓位在 60 天之前就被卖出，上限根本用不上。
- **为什么卖出后换入股票池仍然吃亏**：对选出来的股票，卖掉换成"普通股票"，就丢掉了选股的超额。资产增长的超额要一年才兑现完，所以提前卖出的代价是全年超额的大部分。
- **结论**：
  - 对资产增长这类慢优势，最好的做法接近"选中后持有一年，只用很宽的止损防大亏"。10×ATR42 · 上限 252 与一直持有几乎相同（−0.81%，t −0.73）。
  - 组合回撤都在 −40% 左右，没有一种卖出方式能降低它，与第二十七节一致：组合回撤只能靠大盘层面的仓位控制。

## 三十五、倾斜组合检验（2026-10-30，预登记 `ml_tilt_v1`，516ccaf）

- **起因**：查阅专业做法后发现，机构不会把 IC 0.02 左右的弱信号当成"买前 10%"的名单，而是在整个股票池上做小幅倾斜，同时控制换手（见对话中的文献：Grinold 主动管理基本定律、组合优化中的换手惩罚等）。
- **设计**：
  - 目标权重 = (1 + 综合分截面排名) / N，只做多，单只最多 2 / N；
  - 基准 = 股票池等权；决策日收盘计算，下一个交易日收盘成交；
  - 单边成本 0.05%，按实际换手计；退市按 −30% 结算；
  - 三个变体：每月全部调到目标、每月带缓冲区、每周带缓冲区；在挖掘期选出信息比率最高的变体，再在确认期运行一次。

|---|---|---|---|---|---|---|---|---|
| 挖掘 2004–2015 | 每月全调 | +0.86% | 1.98% | 0.44（1.51） | +0.26% / +1.47% | 138% | −7.9% | 10.0% / 8.9% / 7.2% |

- **判定**：未通过（t 1.18 < 3）。
- **解读**：
  - 用法改进是有效的：同一个信号，"买前 10%"扣成本后约为 0，倾斜组合在两个时期都稳定地带来约 +0.7–0.9%/年，四个半段都为正；

  - 2016 年以后，等权基准本身（12.0%）明显落后 SPY（15.6%）：超大盘股主导。倾斜组合（12.9%）也跑输 SPY。也就是说，在这个综合分上"比随便买略好"成立，但"比买 SPY 好"不成立。
- **按预登记**：不进入持仓计划。若要继续，需要前向检验。

  - **补特征反而更差**：21 日 full 比基线低 0.012（t −2.42，显著为负），主要来自 64 个环境交叉项（−0.010）和行业内排名（−0.003）。交叉项让模型去拟合不同时期，而同样的正则网格压不住约 200 个新输入。
  - **自身历史与板块汇总**：方向为正，两个周期都是，但增量只有 +0.0004 至 +0.0009，t < 1。
  - **深度网络**：两个周期都明显不如岭回归。每个年度版本在 3–6 轮内停止，验证 IC 很不稳定。在每天只有约 1000 个样本、信噪比很低的截面上，网络学不出比线性更多的东西。
  - **多任务**：比单任务略好（21 日 +0.006，t 1.1），不显著。多任务的作用更像正则化，没有超过岭回归。
  - **分板块收缩**：每月选出的 λ 一半是 1000 倍（几乎等于共享模型），另一半是 1 倍，在两端来回跳，说明板块系数没有稳定的信息。
- **结论**：在这个数据和这个股票池上，排名质量的上限仍然是行业中性标签上的岭回归，IC ≈ 0.026。特征工程、非线性、嵌入、多任务、分板块都没有带来增量。确认期（2016 年以后）没有使用。
